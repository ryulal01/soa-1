# Аутентификация и Пользователи:

1. Сервис пользователей с отдельной СУБД (PostgreSQL) для хранения учетных записей.
2. REST API для регистрации, аутентификации, обновления и получения профиля пользователя.
3. Прокси-сервис для маршрутизации запросов и централизованной проверки JWT токенов.
4. OpenAPI спецификации и валидацию входных данных.
5. События регистрации отправляются в Kafka.

# Посты и Промокоды:

1. gRPC сервис для создания, редактирования, удаления и получения постов и промокодов.
2. REST API через прокси-сервис для взаимодействия с gRPC.
3. Работа с приватностью постов, тегами и базовой бизнес-логикой.
4. При взаимодействии с постами и промокодами отправляются события в Kafka (просмотры, лайки, клики, комментарии).

# Комментарии и Взаимодействия:

1. Возможность комментирования постов и промокодов.
2. Реализованы отдельные методы для лайков постов и кликов по промокодам.
3. Все действия публикуются в Kafka для последующей аналитики.

# Сервис статистики:

1. Сервис аналитики на основе ClickHouse.
2. Сервис потребляет события из Kafka и сохраняет данные по просмотрам, лайкам, кликам и комментариям.
3. gRPC API для получения общей статистики и динамики по дням.
4. Добавлены методы получения топ-10 постов, промокодов и пользователей по активности.

# Технологии и Инфраструктура:

gRPC, REST, Kafka, PostgreSQL, ClickHouse, Docker, Docker Compose.

Kafka UI для удобного мониторинга сообщений.

Все REST API через OpenAPI (YML).

Полную обработка ошибок и валидацию входящих данных.

Проект: Социальная сеть


Аутентификация и Пользователи:

Сервис пользователей с отдельной СУБД (PostgreSQL) для хранения учетных записей.
REST API для регистрации, аутентификации, обновления и получения профиля пользователя.
Прокси-сервис для маршрутизации запросов и централизованной проверки JWT токенов.
OpenAPI спецификации и валидацию входных данных.
События регистрации отправляются в Kafka.

Посты и Промокоды:

gRPC сервис для создания, редактирования, удаления и получения постов и промокодов.
REST API через прокси-сервис для взаимодействия с gRPC.
Работа с приватностью постов, тегами и базовой бизнес-логикой.
При взаимодействии с постами и промокодами отправляются события в Kafka (просмотры, лайки, клики, комментарии).

Комментарии и Взаимодействия:

Возможность комментирования постов и промокодов.
Реализованы отдельные методы для лайков постов и кликов по промокодам.
Все действия публикуются в Kafka для последующей аналитики.

Сервис статистики:

Сервис аналитики на основе ClickHouse.
Сервис потребляет события из Kafka и сохраняет данные по просмотрам, лайкам, кликам и комментариям.
gRPC API для получения общей статистики и динамики по дням.
Добавлены методы получения топ-10 постов, промокодов и пользователей по активности.

Технологии и Инфраструктура:

gRPC, REST, Kafka, PostgreSQL, ClickHouse, Docker, Docker Compose.
Kafka UI для удобного мониторинга сообщений.
Все REST API через OpenAPI (YML).
Полную обработка ошибок и валидацию входящих данных.
